# SQL Learning Journey – Real-World HR & Sales Database Project

## Project Overview

This repository documents my 19-day SQL learning journey where I practiced and implemented 70+ real-world SQL queries using a custom-built HR & Sales Management Database.

The objective of this project was to move beyond theoretical SQL concepts and gain practical experience solving business problems using SQL.

---

## Project Goals

* Learn SQL from basic to advanced concepts
* Build a relational database from scratch
* Practice industry-relevant SQL interview questions
* Understand business reporting requirements
* Improve query-writing and analytical thinking skills
* Learn query optimization techniques

## Database Domain

The project is based on an HR & Sales Management System.

### Main Tables

### Relationships

* Department → Employees
